## 1. 当前状态

- 仓库处于混合阶段：
  - `backend/` 是当前运行中的 TypeScript 后端（功能基线基本完整）
  - `backend-go/` 是正在迁移中的 Go 后端（Phase 1 基本完成，准备进入 Phase 2）

- 不要再把本项目理解成"full TypeScript stack"
- Swift 迁移的主战场在 `macapp/`，后端迁移的主战场在 `backend-go/`

## 4. 单次执行规则

- 一次只做 `1` 个执行批次
- 不要跨多个页面
- 不要同时做"页面壳层 + 弹窗 + 业务动作 + 复杂状态"
- 单次建议：
  - 读 Swift 文件 `<= 8`
  - 读 Nuxt 参考文件 `<= 3`
  - 改文件 `<= 4`
  - diff 尽量控制在 `150~350` 行
- 如果预计：
  - 改动 `> 4` 文件，或
  - diff `> 500` 行，或
  - 要同时改 `ViewModel + 多个 View`
  则先继续拆批次

## 7. 每次执行前最少要确认的事

- 当前要做的是哪个批次
- 该批次在 `04` 里的依赖是否满足
- 该批次在 `03` 里的最终验收标准是什么
- 参考的是哪 `1-2` 个 Nuxt 页面
- 这次是否已经超出单次批次边界

## 8. 默认工作方式

- 后端 API 是运行时事实来源，Swift 客户端应适配它
- Web 前端是参考，不是新功能主战场
- 文档与代码不一致时，先确认当前实现，再补文档
- 若任务描述仍然过大，优先拆分，不要硬做
- 涉及UI的实现，需要使用 ui-ux-pro-max skills
