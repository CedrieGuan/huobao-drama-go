# 前端现状分析

> 本文档对 huobao-drama-go 项目现有 Frontend 进行全面梳理，为 Swift 原生化迁移提供精确的功能基准线。

> 补充说明：迁移目标已经确认不是“继续交付 Web 前端”，而是**将现有 Web 产品能力迁移为 macOS 专用客户端**。因此本文档中的 Nuxt 页面与交互用于提炼功能基线，不要求在浏览器端继续保留一套等价实现。

## 3. 页面功能清单

### 3.1 项目列表页 (`pages/index.vue`, 387行)

**路由**: `/`

**功能点**:
- 项目网格展示（`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`）
- 项目卡片：标题、集数徽章、视觉风格标签、角色数、场景数、进度条、更新时间
- 骨架屏加载态（shimmer 动画）
- 空状态引导
- 新建项目模态框（标题 *必填、计划集数、视觉风格选择）
- 删除项目（confirm 确认）
- 胶片装饰条（film strip）
- 悬浮动效（上移 + 阴影 + 边框高亮）
- 时间格式化（刚刚/X分钟前/X小时前/X天前/日期）

**数据交互**:
- `dramaAPI.list()` → 获取项目列表
- `dramaAPI.create(form)` → 创建项目
- `dramaAPI.del(id)` → 删除项目

### 3.2 剧集详情页 (`pages/drama/[id]/index.vue`, 501行)

**路由**: `/drama/[id]`

**功能点**:
- 项目信息头部（标题、风格标签、角色数、场景数）
- 返回按钮
- 剧集列表（纵向卡片列表）
  - 集号显示（E01、E02...）
  - 剧本状态（已完成/待编写）
  - 时长显示
  - 箭头导航动效
- 添加新集对话框（**配置锁定机制**）
  - 标题输入（可选，默认按集数命名）
  - 图片配置选择（必选）
  - 视频配置选择（必选）
  - 音频配置选择（必选）
  - 创建后配置不可更改
- 空状态

**数据交互**:
- `dramaAPI.get(id)` → 获取项目详情（含 episodes/characters/scenes）
- `aiConfigAPI.list('image')` → 图片服务配置
- `aiConfigAPI.list('video')` → 视频服务配置
- `aiConfigAPI.list('audio')` → 音频服务配置
- `episodeAPI.create(data)` → 创建剧集

#### 3.3.2 Pipeline 侧边栏（11 步流水线）

分三个区段：

**剧本区段（script panel）**:
| 步骤 | Key | 标签 | 功能 |
|------|-----|------|------|
| 01 | raw_content | 原始内容 | 粘贴小说/故事原文，textarea 编辑，字数统计，保存 |
| 02 | script_rewrite | AI 改写 | Agent 调用 script_rewriter，加载态，可跳过，可重新改写 |
| 03 | extract | 提取角色与场景 | Agent 调用 extractor，展示角色列表+场景列表，提取结果面板 |
| 04 | voice_assign | 分配音色 | Agent 调用 voice_assigner，音色选择器，音色库面板，试听生成，audio 播放器 |
| 05 | storyboard | 分镜列表 | Agent 调用 storyboard_breaker，镜头序列+详情面板，字段编辑，提示词编辑 |

**制作区段（production panel）— 6个子标签页**:
| Tab | Key | 标签 | 功能 |
|-----|-----|------|------|
| 1 | chars | 角色形象 | 角色图片网格，单张生成，批量生成，pending 态管理 |
| 2 | scenes | 场景图片 | 场景图片网格，单张生成，批量生成 |
| 3 | dubbing | 配音 | 对白镜头列表，TTS 生成，audio 播放器，批量生成 |
| 4 | shots | 帧图 + Grid工具 | 首帧/尾帧生成，宫格图工具（5步流程），Grid历史，pending管理 |
| 5 | videos | 视频 | 视频生成，视频播放器，批量生成，失败信息展示 |
| 6 | compose | 合成 | 视频+配音合成，合成状态轮询，批量合成 |

**导出区段（export panel）**:
| 步骤 | 功能 |
|------|------|
| 全集拼接 | 将所有合成镜头合并为完整视频，下载链接 |

#### 3.3.3 Grid 宫格图工具（核心子功能）

位于 shots 标签页内的对话框工具，5步流程：

| 步骤 | 功能 |
|------|------|
| Step 0 配置 | 选择模式（首帧/首尾帧/多参考）、宫格布局（2x2~5x5）、选择镜头 |
| Step 1 提示词 | AI 生成宫格图提示词，预览模板，手动编辑 |
| Step 2 生成 | 调用图片生成 API，轮询状态 |
| Step 3 切分分配 | 预览宫格图，格子→镜头映射，分页管理 |
| Step 4 完成 | 分配结果确认 |

Grid 工具的状态管理包含 30+ 个 ref 变量，是前端最复杂的单一功能。

#### 3.3.4 分镜详情面板字段

选中分镜后右侧展示完整编辑表单：

**镜头结构**:
- 标题、景别（datalist）、角度（datalist）、运镜（datalist）
- 绑定角色（pill 多选）、绑定场景（下拉）
- 地点、时间、时长

**画面语义**:
- 动作、结果、画面描述、氛围
- 对白/旁白

**生成提示**:
- 静态画面提示词
- 视频提示词
- 配乐提示词
- 音效提示词

**预览区**:
- 首帧预览图（可点击放大）
- 尾帧预览图（可点击放大）

#### 3.3.5 底部步骤导航气泡

固定在内容区底部，包含：
- 上一步/下一步按钮
- 进度点（dot indicators）
- 自动判断可前进/后退条件
- 在 script/production 面板之间切换逻辑

#### 3.4.1 AI 服务配置

**火宝推荐配置面板**:
- 一键配置按钮 → 输入 API Key → 自动创建 4 条服务配置
- 预览卡片展示：文本(chatfire)、图片(gemini)、视频(volcengine)、音频(minimax)

**快捷模板**:
- 4种服务类型快速添加按钮（文本/图片/视频/音频）

**服务列表（按类型分组）**:
- 每条配置显示：provider、name、model、base_url
- 密钥状态标签
- 测试按钮（调用 `/ai-configs/test`）
- 启用/禁用开关
- 编辑/删除按钮

**配置编辑对话框**:
- 模板快捷选择（providerPresets，内置 8 个服务商 × 4 种类型）
- 字段：name、provider（8个选项）、priority、api_key、base_url、model（逗号分隔）
- 端点前缀自动提示（endpointPrefixes 映射）
- 测试结果展示（可达/不可达、状态码、响应预览）

**服务商列表**:
| provider | 支持类型 |
|----------|----------|
| ali | video |
| chatfire | text, image |
| gemini | image |
| minimax | audio |
| openai | text |
| openrouter | text |
| vidu | video |
| volcengine | image, video |

#### 3.4.2 Agent 配置

**3个 Agent 类型**:
| type | 标签 | 图标 |
|------|------|------|
| script_rewriter | 剧本改写 | 📝 |
| extractor | 角色场景提取 | 🔍 |
| storyboard_breaker | 分镜拆解 | 🎬 |

**配置字段**（折叠卡片形式）:
- 模型选择（从已启用的 text 类型配置中获取选项）
- Temperature（0~2，step 0.1）
- Max Tokens（100~32000）
- System Prompt（textarea，可恢复默认）

#### 3.4.3 Skills 管理

- 左侧：Agent 列表切换
- 右侧：当前 Agent 的 Skill 列表
- Skill 操作：新增（id + name + description）、编辑（Markdown textarea）、删除
- Skill 内容存储路径：`skills/{agent_type}/{skill_id}/SKILL.md`

## 9. 关键交互流程

### 9.1 完整制作流水线

```
新建项目 → 新建集（锁定配置）→ 工作台
  ↓
[Step 01] 粘贴原始内容 → 保存
  ↓
[Step 02] AI 改写（可跳过）
  ↓
[Step 03] AI 提取角色与场景
  ↓
[Step 04] AI 分配音色 → 手动调整 → 生成试听
  ↓
[Step 05] AI 拆解分镜 → 手动编辑分镜字段
  ↓
[Production]
  ├─ 角色形象图（单张/批量生成）
  ├─ 场景图（单张/批量生成）
  ├─ 配音 TTS（单条/批量生成）
  ├─ 帧图 + Grid宫格图工具（核心）
  ├─ 视频生成（单条/批量）
  └─ 合成（视频+音频）
  ↓
[Export] 全集拼接 → 下载
```

### 9.2 Grid 宫格图工具流程

```
选择模式+布局+镜头 → 生成提示词(AI) → 预览提示词
  → 调用图片生成 → 轮询状态 → 预览宫格图
  → 格子分配映射 → 切分 → 完成
```

### 9.3 异步任务管理

前端通过 pending 列表管理异步任务状态：

| Pending 列表 | 用途 |
|-------------|------|
| `pendingCharImageIds` | 角色图生成中 |
| `pendingSceneImageIds` | 场景图生成中 |
| `pendingShotFrameKeys` | 帧图生成中（key = `id:frameType`） |
| `pendingVideoIds` | 视频生成中 |
| `pendingComposeIds` | 合成中 |
| `failedVideoMessages` | 视频生成失败信息 |
| `failedComposeMessages` | 合成失败信息 |

## 11. 现有局限与痛点
